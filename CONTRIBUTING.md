# Contributing

Use issues or discussions for large features, new dependencies, schema changes,
and security-sensitive work. Every commit requires a `Signed-off-by:` line under
the Developer Certificate of Origin 1.1: <https://developercertificate.org/>.
Contributors retain copyright; contributions use Apache-2.0. There is no CLA.

Run the full test suite and describe Core compatibility and data-schema effects.
Core changes must be generic and demonstrated by another application.
